# Shared Research Website (Scaffold)

Planned team-facing website for J26-IT-449. **No website implementation or authentication is included yet.**

- `frontend/`: user interface and pages after the frontend framework is selected.
- `backend/`: server/API and authentication after the backend framework is selected.

Before implementation, decide whether to extend the existing Python Gradio demo or create a separate web frontend and API. Do not introduce a second stack without team agreement.

Existing Buddhi demo remains at repository root `demo/app.py` and is unchanged.
